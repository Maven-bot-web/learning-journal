# 学习日志

这个仓库用来记录我从 Linux 基础、运维、自动化、网络到云安全方向的学习过程。

它不只是笔记本，更是一条可以回看的学习证据链：我学了什么、做了什么、哪里出错、最后怎么解决。

## 当前阶段

第一阶段：Linux 基础和基础运维能力。

当前目标是：拿到一台 Linux 机器后，能独立完成一次基础体检。

- 判断系统版本和内核信息
- 查看磁盘和内存使用情况
- 理解 IP 地址、路由和默认网关
- 查看正在运行的进程
- 查看正在监听的端口
- 用 Bash 脚本自动化常见检查

## 目录说明

```text
daily/        每日学习记录
notes/        整理后的知识笔记
labs/         动手实验记录
scripts/      学习过程中写的小脚本
resources/    常用命令、清单和参考资料
```

## 使用方式

每次学习结束后，至少留下一点记录：

1. 在 `daily/` 里写今天做了什么
2. 把重要概念整理到 `notes/`
3. 把动手实验记录到 `labs/`
4. 把可复用的小脚本放到 `scripts/`
5. 用清晰的提交信息提交到 Git
