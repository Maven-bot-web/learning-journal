它负责记录路线、计划、复习、验收和项目复盘；真正的脚本、代码、Docker、CI/CD、排障实验放在 `infra-ops-lab`。


## 执行模型

```text
我们制定路线
↓

↓

↓
自己的 infra-ops-lab 项目负责验收
```

详细说明见：`EXECUTION_MODEL.md`
